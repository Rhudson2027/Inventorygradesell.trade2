# InventoryGradeSell - 2020 Topps Database (GitHub Pages)

Same layout and same work as the master database.

- Search, filter by set, Qty, Have, Notes
- Export CSV
- Saves in browser (localStorage)

## Deploy
Upload index.html, CNAME, .nojekyll, README.md to repo root. Settings > Pages > Deploy from branch main / root. Custom domain: inventorygradesell.trade

## DNS
In domain registrar: 4 A records for @: 185.199.108.153, 185.199.109.153, 185.199.110.153, 185.199.111.153. CNAME www -> <your-github-username>.github.io
